# KUNALYT0 PAK TOOL

PAK/Skin modding tool for BGMI/PUBG on Android Termux.

## Install

curl -fsSL https://raw.githubusercontent.com/pikunp909-dot/kunalyt0-pak-tool/main/install.sh | bash && kunalyt0

## Features
- PAK Unpack / Repack
- Skin Modding (Mini + ZSDIC)
- Lua Decompile / Recompile
- UE4 String Editor
- Auto Mod Making
- 16-layer encryption

## Troubleshooting

pip install rich requests pycryptodome zstandard gmalg colorama termcolor pytz

## Uninstall

rm -rf ~/.kunalyt0
rm -f $PREFIX/bin/kunalyt0
